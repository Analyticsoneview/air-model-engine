# AIR Telegram notifications

The backend can send strategy notifications to the configured private Telegram chat and AIR group. The bot token is never stored in source control or the mobile app.

## Docker Swarm deployment

Create a Swarm secret from the **replacement token** generated by BotFather. Run this on the Swarm manager; never paste the token into GitHub or ChatGPT:

```sh
printf '%s' 'YOUR_REPLACEMENT_BOT_TOKEN' | docker secret create air_telegram_bot_token -
```

Set these deployment variables in the Swarm deployment environment:

```text
AIR_TELEGRAM_CHAT_IDS=8612595451,-1004387804807
AIR_TELEGRAM_SCHEDULER_ENABLED=true
```

The stack mounts the external secret at `/run/secrets/air_telegram_bot_token` and configures:

```text
AIR_TELEGRAM_BOT_TOKEN_FILE=/run/secrets/air_telegram_bot_token
AIR_TELEGRAM_DEDUPE_DB_PATH=/var/lib/air/air_telegram_notifications.sqlite3
```

Verify the group ID from Telegram's `getUpdates` response before deployment. Use the exact signed `chat.id` value (supergroup IDs are normally negative). The SQLite deduplication database is stored on the persistent `air_data` volume.

## Test delivery

After deploying, authenticate as an AIR operator and call:

```http
POST /api/v1/model-engine/telegram/test
```

A successful response should report `sent: 2` and no failures. This confirms the private and group destinations independently.

## Scheduled polling

When `AIR_TELEGRAM_SCHEDULER_ENABLED=true`, the backend polls RECOVERED, EXPIRY78 and EXPIRYSCAN every five minutes on weekdays during 09:00-15:59 Asia/Kolkata. It uses already persisted/verified Model Engine data; it does not fetch fresh option-chain data, invent signals, or place broker orders. EXPIRYSCAN can only alert on snapshots already captured by the AIR QOC data-capture pipeline.

The scheduler is disabled by default. Configure the Dhan account and enable the existing AIR QOC capture scheduler separately if fresh EXPIRYSCAN observations are required.

## Alert meaning

- **RECOVERED:** historical recovery model / watch-only; not a live position or fresh buy instruction.
- **EXPIRY78:** research candidate and lifecycle updates; no broker orders.
- **EXPIRYSCAN:** liquidity-screen pass only; not a fully qualified AIR QOC trade.
- Alerts are deduplicated by strategy, contract, status and destination. Failed sends are eligible for retry on the next poll.
- The authenticated test route is restricted to configured AIR operator accounts.

## Security

Never commit the bot token, send it in Telegram, or expose it to the frontend. If the token is rotated, update the Swarm secret and redeploy the service.
